Description: Simulates power for non-inferiority tests in repeated cross-sectional
    stepped-wedge cluster randomized trials with binary or continuous outcomes.
    The package supports fixed categorical period adjustment, user-specified
    secular period effects, unequal numbers of clusters across sequences,
    unequal cluster-period sample sizes, parameter grids, reproducible optional
    parallelization, conservative handling of failed model fits, Monte Carlo
    standard errors, optional Word export, and an optional Shiny interface.
