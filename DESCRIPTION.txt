Description: Simulates power for non-inferiority tests in repeated cross-sectional
    stepped-wedge cluster randomized trials with binary or continuous outcomes.
    Supports batched PyTorch GPU and CPU acceleration with JIT-compiled fused
    CUDA kernels for random-intercept and AR(1) cluster-period mixed models
    (including zero-setup execution on Google Colab via 'reticulate' or Python
    CLI) alongside the reference 'lme4' engine, fixed categorical period
    adjustment, user-specified secular period effects, unequal numbers of
    clusters across sequences, unequal cluster-period sample sizes, parameter
    grids, conservative handling of failed model fits, Monte Carlo standard
    errors, optional Word export, and an optional Shiny interface.
